# Lynx 安装程序重设计规格

## 1. 背景与目标

当前 `desktop-native/installer.nsi` 自定义安装页在 Windows 上渲染异常（见截图）：自定义页面空白、Logo 错位、底部文字截断。本次重设计目标：

1. 修复安装程序无法正常进行的问题；
2. 安装包命名规范改为 `lynx_1.0.0.exe`，产品版本统一回退到 `1.0.0`；
3. 安装界面采用 iOS 液态玻璃极简风格，配色为深海蓝 + 黑/白/灰；
4. 完整构建并运行桌面端验证效果。

## 2. 设计方案

### 2.1 技术方案

采用 **NSIS 全位图自定义页（方案 B）**：

- 用 HTML/CSS 设计好安装页背景图（520×420），导出为 BMP；
- NSIS 使用 `nsDialogs` 创建全尺寸自定义页面，背景贴图；
- 控件（路径输入、浏览按钮、复选框、立即安装按钮、进度条）使用标准 nsDialogs 控件，但覆盖在背景图上；
- 按钮和进度条通过颜色/字体尽量贴近设计；
- 保持与现有构建链兼容：Tauri 构建 → `build-native.ps1` → NSIS 编译。

不引入 WPF/Electron 独立安装器，避免额外工作量和依赖。

### 2.2 视觉方案（深色 Deep Sea）

- **背景**：深海蓝渐变 `#0c1a2d` → `#091425` → `#060d18`，叠加两处蓝色光晕；
- **玻璃面板**：半透明白色 `rgba(255,255,255,0.06)`，1px 细边框 `rgba(255,255,255,0.14)`，顶部内发光；
- **主按钮**：蓝色渐变 `#3b82f6` → `#1d4ed8`，圆角 14px，白色文字；
- **次要按钮/输入框**：半透明玻璃背景，细边框；
- **文字**：主文字 `rgba(255,255,255,0.92)`，次级 `0.48`，弱化 `0.35`；
- **进度条**：蓝色发光进度条，轨道 `rgba(255,255,255,0.07)`。

### 2.3 页面流程

1. **安装页**：大 Logo + 标题 + 安装路径输入 + 创建桌面快捷方式复选框 + 立即安装按钮；
2. **进度页**：大 Logo + 标题 + 平滑进度条 + 当前步骤文案；
3. **完成页**：成功图标 + 标题 + 立即体验按钮（自动启动 Lynx）。

## 3. 版本规范

- 当前版本统一为 `1.0.0`；
- 安装包文件名：`lynx_1.0.0.exe`；
- 安装目录默认：`$PROGRAMFILES64\Lynx`；
- 后续迭代版本号规则：
  - 小迭代：`+0.01`（如 1.0.1）
  - 中等升级：`+0.1`（如 1.1.0）
  - 大版本升级：`+1`（如 2.0.0）
- 该规则需写入 `DEVELOPMENT_SPEC.md` 并持续遵守。

## 4. 文件变更

- `desktop-native/installer.nsi`：重绘自定义安装页、进度页、完成页，统一深海蓝玻璃风格；
- `desktop-native/build-native.ps1`：输出文件名改为 `lynx_1.0.0.exe`；
- `desktop-native/package.json`：`version` 改为 `1.0.0`；
- `desktop-native/src-tauri/Cargo.toml`：`version` 改为 `1.0.0`；
- `desktop-native/src-tauri/tauri.conf.json`：`version` 改为 `1.0.0`；
- `desktop-native/native-ui/package.json`：`version` 改为 `1.0.0`；
- `DEVELOPMENT_SPEC.md`：新增版本号更新规范。

## 5. 验证标准

- `build-native.ps1` 完整构建通过；
- 生成 `desktop-native/dist/lynx_1.0.0.exe`；
- 安装程序能正常打开并走完安装流程；
- 安装完成后能启动 Lynx 桌面端；
- 桌面端 `tauri dev` 或构建后可运行并查看原生 UI 效果。
