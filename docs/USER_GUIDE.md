## 1. 快速开始

### 1.1 登录

- 打开 LynnHub 首页，未登录会自动跳转到 `/login`。
- 输入管理员分配的**用户名**和**密码**，点击「登录」。
- 登录基于 NextAuth.js，会话有效期 7 天，期间无需重复登录。
- 若登录失败，请检查：
  - 用户名/密码是否正确；
  - 账号是否被管理员停用（`active=false`）；
  - 是否触发登录限流（10 次/分钟）。

### 1.2 角色说明

| 角色 | 权限 |
| --- | --- |
| `admin`（管理员） | 全部功能，可访问所有用户数据、用户管理、角色管理、词元统计、职业空间、系统设置、数据备份 |
| `editor`（编辑者） | 可访问本人数据，使用所有个人功能（灵感/看板/认知/记忆/技能/AI 助理等），无管理权限 |
| `viewer`（浏览者） | 只读浏览本人数据，不可创建/修改/删除（可选角色，由管理员分配） |

角色由管理员在「管理后台 → 用户管理」中分配，角色权限基于 35 项细粒度权限配置。

### 1.3 基本导航

LynnHub 采用左侧边栏 + 顶部捕获栏的双栏布局：

- **左侧边栏**：按功能分组（今日执行 / 灵感收集 / 知识资产 / 周期仪式 / AI 中心 / 系统），点击组标题可展开/折叠子项。桌面端可点击顶部 `PanelLeft` 图标收起侧边栏以获得更宽的工作区；移动端点击左上角菜单按钮唤出。
- **顶部捕获栏**：始终可见，提供「闪电输入」「全局搜索」「Inbox 计数」「主题切换」四个快捷入口。
- **当前页面**：显示在主内容区，每个页面顶部有 `PageHeader` 标题与说明。

### 1.4 主题切换

- 顶部捕获栏右侧有主题切换控件，支持**浅色 / 深色 / 跟随系统**三种模式。
- 选择会持久化到本地存储，下次访问自动恢复。

## 2. 灵感管理

灵感是 LynnHub 的最小信息单元。完整生命周期：**闪电输入 → Inbox → 决策看板 / 灵感墓地**。

### 2.1 闪电输入

- **触发方式**：
  - 点击顶部捕获栏的「捕获灵感」按钮；
  - 按快捷键 `Ctrl+J`（macOS 为 `Cmd+J`）；
  - 在全局搜索（`Ctrl+K`）中输入 `>new`。
- **使用方法**：
  1. 弹出居中输入框，输入灵感内容（最多 5000 字符）；
  2. 按 `Enter` 保存并关闭，按 `Shift+Enter` 换行；
  3. 按 `Esc` 取消关闭。
- 保存成功后灵感会进入 **Inbox**，同时异步写入记忆图谱用于后续语义检索。

### 2.2 Inbox（灵感收件箱）

- 路径：侧边栏「灵感收集 → Inbox」，或顶部捕获栏的 Inbox 徽标。
- 显示所有待处理的灵感（`status=inbox`），按创建时间倒序，最多 50 条。
- 每条灵感可执行三种决策：
  - **拖入看板**：选择目标列（北极星 / 战役 / 任务），灵感转化为任务进入决策看板。
  - **延后**：暂时不决策，灵感保留在 Inbox。
  - **放弃入墓地**：填写放弃理由和复活条件，灵感进入灵感墓地。
- **看板列满额阻断**：
  - 北极星 ≤ 3 条；
  - 战役 ≤ 5 条；
  - 任务 ≤ 10 条。
  - 超限时拖入会返回 409 错误，需先清理目标列。

### 2.3 决策看板

- 路径：侧边栏「今日执行 → 决策看板」（`/board`）。
- 三列看板：
  - **北极星**（northstar）：长期最重要的 1–3 个目标；
  - **战役**（campaign）：阶段性重点，最多 5 个；
  - **任务**（task）：当前执行中的具体任务，最多 10 个。
- **操作**：
  - 拖拽任务在列内排序或跨列移动（同样受满额限制）；
  - 点击任务可编辑内容；
  - 标记完成 / 删除（软删除，`status=dropped`）。
- 看板任务会参与「今日聚焦」的每日挑选。

### 2.4 灵感墓地

- 路径：侧边栏「灵感收集 → 灵感墓地」（`/graveyard`）。
- 存放所有被放弃的灵感，保留**放弃理由**和**复活条件**。
- **AI 巡检复活**：
  - 系统定期检查墓地灵感的复活条件是否被最近 7 天的新灵感命中；
  - 匹配优先级：embedding 语义匹配 > AI 文本判断 > 关键词匹配；
  - 命中后会给出复活建议，用户可决定是否将灵感重新拉回 Inbox 或看板。

### 2.5 收敛仪式

- 路径：侧边栏「周期仪式 → 收敛仪式」（`/converge`）。
- 每日/每周的灵感收敛流程：批量处理 Inbox 中的灵感，快速决策拖入看板或入墓地。
- 页面顶部显示实时倒计时，帮助控制收敛节奏。

## 3. 知识资产

知识资产模块负责沉淀对话、认知和长期记忆，形成可复利的知识网络。

### 3.1 对话资产（对话捕获）

- 路径：侧边栏「知识资产 → 对话资产」（`/assets`）。
- 捕获来源：
  - 闪电输入时选择 `source=conversation`；
  - AI 对话中标记收藏的消息；
  - 飞书机器人推送的对话片段。
- 列表展示对话片段，支持按来源筛选、关键词搜索。
- 每条对话可转化为「认知」进入认知库。

### 3.2 认知库

- 路径：侧边栏「知识资产 → 认知库」（`/cognition`）。
- 认知类型分组（3 种）：
  - **方法**（method）：可复用的方法论、流程、框架
  - **经验**（experience）：从实践中总结的经验教训、心得体会
  - **提示词**（prompt）：精选的 AI 提示词模板
- **操作**：
  - 新增认知（支持富文本）；
  - 编辑、删除；
  - 关联到记忆图谱节点。
- 认知库支持语义搜索（AI 向量优先，TF-IDF 降级）。
- 认知可由 AI 自动从完成的任务、对话资产中提取，也可手动创建。

### 3.3 记忆图谱

- 路径：侧边栏「知识资产 → 记忆图谱」（`/memory`）。
- 自动构建：每条灵感/认知/对话写入时，异步抽取实体与关系，形成图谱节点。
- **功能**：
  - 节点列表浏览，按类型筛选；
  - 节点详情：关联的灵感、认知、对话；
  - 语义搜索：输入关键词，返回最相关的记忆节点。
- 记忆图谱是 AI 助理「长期记忆」的数据来源。

## 4. AI 中心

AI 中心提供工作空间、工作流、专属助理、技能库等能力，是 LynnHub 的智能引擎。

### 4.1 AI 工作空间

- 路径：侧边栏「AI 中心 → AI 工作空间」（`/ai/workspace`）。
- 多会话聊天界面，支持：
  - 新建/切换/置顶/删除会话；
  - 选择 AI 提供商与模型（通过 `ModelSwitcher`）；
  - 上传图片（多模态）；
  - 流式输出（SSE）实时显示回复。
- 会话消息持久化到数据库，跨设备同步。
- 管理员可访问所有用户的会话；普通用户仅可访问自己的会话。

### 4.2 AI 工作流（Flows）

- 路径：侧边栏「AI 中心 → AI 工作流」（`/ai/flows`）。
- 可视化编排多步骤 AI 任务，支持：
  - 节点类型：LLM 调用、条件分支、HTTP 请求、代码执行、记忆读写；
  - 条件分支可视化展示；
  - 手动触发执行；
  - 定时调度（cron 表达式）；
  - 执行历史持久化，可回溯每次执行的输入输出。
- 调度器状态可在「管理 → 性能监控」查看。

### 4.3 AI 专属助理

- 路径：侧边栏「AI 中心 → AI 专属助理」（`/ai/assistant`）。
- 与通用工作空间不同，专属助理：
  - 自动注入用户长期记忆（记忆图谱）作为上下文；
  - 可调用技能库中的技能；
  - 支持语音输入（ASR）和语音合成（TTS）；
  - 支持语音克隆（需管理员授权）。

### 4.4 技能管理

- 路径：侧边栏「AI 中心 → 技能管理」（`/skills`）。
- 技能是可复用的 AI 能力单元（提示词模板 + 工具调用）。
- **功能**：
  - 新建技能（支持版本管理）；
  - 编辑、删除、启用/停用；
  - 版本回滚；
  - 代码审查（review）记录；
  - 导出/导入技能（JSON 格式）；
  - 生成分享码，供其他用户导入。
- **Skill 市场**（`/skills/market`）：浏览通过分享码分享的技能，一键导入。

### 4.5 飞书任务

- 路径：侧边栏「AI 中心 → 飞书任务」（`/ai/lark-tasks`）。
- 与飞书任务系统双向同步：
  - 拉取飞书任务到本地；
  - 推送本地任务到飞书；
  - 管理子任务、评论、关注者、负责人；
  - 接收飞书 Webhook 事件实时更新。
- 需在「管理 → 飞书机器人」配置应用凭证。

## 5. 个人设置

个人设置模块对所有用户开放，用于管理个人资料、AI 配置、通知订阅等。

### 5.1 个人资料

- 路径：侧边栏「设置 → 个人资料」（`/settings/profile`）。
- **功能**：
  - 修改显示名、邮箱、头像
  - 修改登录密码
  - 查看账号角色与职业

### 5.2 AI 配置

- 路径：侧边栏「设置 → AI 配置」（`/settings/ai`）。
- **功能**：
  - 配置个人 AI 大模型 API Key（DeepSeek / MiMo）
  - 选择默认 AI 提供商与模型
  - 配置个人使用的 AI Key 后，AI 对话将优先使用个人 Key

### 5.3 通知设置

- 路径：侧边栏「设置 → 通知」（`/settings/push`）。
- 基于 Web Push API + VAPID 实现。
- **功能**：
  - 订阅/取消订阅浏览器通知
  - 发送测试通知验证
  - 配置通知触发场景（任务到期、灵感复活、AI 工作流完成等）
- **注意**：通知需要用户在浏览器端授权，且仅在应用打开时可通过 Service Worker 推送。

### 5.4 远程操控（桌面端）

- 路径：侧边栏「设置 → 远程操控」（`/settings/remote-control`）。
- **功能**：
  - 查看同账号下已登录的 PC 设备列表与在线状态
  - 向目标 PC 下发远程指令
  - 查看指令执行历史与状态
- 需桌面端（Tauri）登录后才能使用远程操控功能。

## 6. 系统管理（管理员）

系统管理模块仅 `admin` 角色可见，普通用户访问会返回 403。

### 6.1 设置总览

- 路径：侧边栏「管理 → 系统设置」（`/settings`）。
- 显示：
  - 数据库连接状态与各表数据量；
  - AI 配置（聊天模型、Embedding 模型、是否启用）；
  - 环境变量文件路径（`.env` 与 `.env.example`）。
- 用于快速诊断系统是否正常运行。

### 6.2 用户管理

- 路径：侧边栏「管理 → 用户管理」（`/admin/users`）。
- **功能**：
  - 查看所有用户列表；
  - 新增用户（用户名、显示名、邮箱、密码、角色）；
  - 编辑用户信息、修改角色；
  - 启用/停用账号（`active` 字段）；
  - 重置密码；
  - 删除用户（软删除）。
- 密码使用 bcrypt 哈希存储，不可逆。

### 6.3 角色管理

- 路径：侧边栏「管理 → 角色管理」（`/admin/roles`）。
- **功能**：
  - 查看所有角色及其权限列表
  - 新建自定义角色（设置名称、显示名、关联职业、权限分配）
  - 编辑角色权限
  - 删除非系统角色（有用户使用时拒绝删除）
- 系统内置 3 个角色：admin / editor / viewer，不可删除。

### 6.4 词元统计

- 路径：侧边栏「管理 → 词元统计」（`/admin/token-stats`）。
- **功能**：
  - 4 个统计卡片：今日 / 昨日 / 近 7 天 / 累计
  - 按 AI 提供商分布的消耗柱状图
  - 用户切换：按指定用户查看统计
  - 词元排行榜：金/银/铜排名样式
  - 消耗记录分页表格

### 6.5 职业空间

- 路径：侧边栏「管理 → 职业空间」（`/admin/profession-workspaces`）。
- **功能**：
  - 12 个岗位的定制化配置
  - 专属功能模块、可用 AI 模型、System Prompt、工具白名单
  - 一键重置为默认配置

### 6.6 数据备份

- 路径：侧边栏「管理 → 数据备份」（`/settings/backup`）。
- **导出**：
  - 一键导出全部核心数据（Idea / Task / Conversation / Cognition / Memory / Skill 等 23 类）为 JSON；
  - 可选择导出范围（全部 / 按数据类型）。
- **导入**：
  - 上传 JSON 文件恢复数据；
  - 支持增量导入（按 ID 去重）。
- **建议**：定期（每周）导出一次备份，防止数据丢失。

### 6.7 飞书机器人

- 路径：侧边栏「管理 → 飞书机器人」（`/settings/lark-bot`）。
- 配置飞书应用凭证：
  - App ID、App Secret；
  - Verification Token、Encrypt Key（用于 Webhook）；
  - 事件订阅地址（`/api/lark-webhook`）。
- **功能**：
  - 发送测试消息验证连通性；
  - 查看 Webhook 事件接收日志；
  - 模拟事件触发（用于开发调试）。
- 配置完成后，飞书任务同步、AI 通知推送等功能才可用。

### 6.8 性能监控

- 路径：侧边栏「管理 → 性能监控」（`/settings/diagnostics`）。
- 显示：
  - 数据库各表记录数与分布（灵感状态、任务状态、看板列）；
  - Embedding 缓存命中率与模式（AI 向量 / TF-IDF 降级）；
  - Flows 调度器运行状态、计划任务数；
  - 进程内存使用（RSS / Heap / External）；
  - 进程运行时间、Node 版本、操作系统。
- 用于排查性能问题与系统健康检查。

### 6.9 巡检规则

- 路径：侧边栏「管理 → 巡检规则」（`/settings/patrol`）。
- **功能**：
  - 配置自动化巡检规则（灵感去重、Graveyard 复活检查等）
  - 设置执行时间（每日定时或自定义 cron 表达式）
  - 配置通知渠道（站内信、飞书、Web Push）
  - 查看巡检执行历史

### 6.10 开发日志

- 路径：侧边栏「管理 → 开发日志」（`/dev-log`）。
- 记录系统开发迭代历史与变更点，便于追溯功能演进。

## 7. 快捷键说明

| 快捷键 | 功能 | 说明 |
| --- | --- | --- |
| `Ctrl+J` / `Cmd+J` | 打开闪电输入 | 全局可用，随时捕获灵感 |

### 全局搜索进阶用法

- 输入 `>` 开头触发快捷命令：
  - `>board` 跳转决策看板
  - `>inbox` 跳转 Inbox
  - `>memory` 跳转记忆图谱
  - `>new` 打开闪电输入
  - `>search 关键词` 执行全局搜索
- 支持中文拼音首字母匹配（如输入 `kb` 可匹配「看板」）。
- 搜索结果按类型分页签过滤：全部 / 页面 / 任务 / 灵感 / 认知 / 记忆 / 技能。
- 最近搜索记录会保存在本地（最多 8 条）。

## 8. FAQ

### Q1：忘记密码怎么办？

普通用户请联系管理员重置密码；管理员忘记密码需直接操作数据库，使用 bcrypt 生成新哈希后更新 `User.passwordHash` 字段。

### Q2：灵感被误入墓地，如何恢复？

进入「灵感墓地」，找到对应灵感，点击「复活」按钮即可将其重新拉回 Inbox。系统也会定期通过 AI 巡检自动建议可复活的灵感。

### Q3：看板列满了无法添加新任务？

LynnHub 对看板列有硬性上限（北极星 3 / 战役 5 / 任务 10），这是为了保持聚焦。请先完成或删除现有任务腾出位置，再添加新任务。

### Q4：AI 功能不工作？

1. 进入「管理 → 系统设置」检查 AI 配置是否启用、模型与 Base URL 是否正确；
2. 检查 `.env` 中的 API Key 是否配置；
3. 查看「性能监控」中 Embedding 模式：若显示「TF-IDF 降级」说明 AI 向量未启用，语义搜索仍可用但精度降低；
4. 聊天功能失败时会在页面顶部弹出 Toast 错误提示。

### Q5：数据会丢失吗？

- 数据存储在 MySQL 数据库中，可靠性取决于数据库配置。
- 建议管理员定期使用「数据备份」功能导出 JSON 备份。
- 软删除的数据（任务 `dropped`、用户 `active=false`）仍保留在数据库，可恢复。

### Q6：移动端可以使用吗？

可以。LynnHub 是响应式设计，移动端：
- 侧边栏变为抽屉式，点击左上角菜单按钮唤出；
- 顶部捕获栏简化，仅显示图标；
- 支持添加到主屏幕作为 PWA 应用（需通过 HTTPS 访问）。

### Q7：如何切换深色模式？

点击顶部捕获栏右侧的主题切换控件，选择「浅色 / 深色 / 跟随系统」。选择会持久化，下次访问自动恢复。

### Q8：多个用户可以同时使用吗？

可以。LynnHub 支持多用户，每个用户的数据相互隔离（管理员除外）。AI 会话、灵感、任务等均按用户归属，普通用户无法访问他人数据。

### Q9：飞书机器人如何配置？

1. 在飞书开放平台创建企业自建应用；
2. 获取 App ID、App Secret、Verification Token、Encrypt Key；
3. 在「管理 → 飞书机器人」页面填入凭证；
4. 配置事件订阅地址为 `https://你的域名/api/lark-webhook`；
5. 点击「发送测试消息」验证连通性。

### Q10：如何关闭浏览器通知？

进入「设置 → 通知」，点击「取消订阅」即可。若要彻底关闭，可在浏览器设置中移除该站点的通知权限。
